Production notes

The previous Windows beta has been withdrawn. Public downloads are paused while the native application is simplified and verified against real Windows behaviour.

What is being removed

  • The permanent floating toolbar.
  • The first-run onboarding tour.
  • The manual target-selection workflow during normal shortcut use.
  • The saved-notes widget floating over other applications.
  • Any public installer that opens a terminal or blocks unrelated screen interaction.

What the next build must do

  • Start quietly in the system tray without a console window.
  • Create one note for the foreground application with Ctrl + Shift + Space.
  • Keep empty overlay space click-through.
  • Provide clear save, close, hide, delete, and quit controls.
  • Use a natural paper-note typography treatment.
  • Regenerate every installer icon from the approved Skribli branding asset.

Why downloads are paused

A release should not be public merely because it compiles. The next installer will be published only after native Windows runtime checks confirm that it behaves safely across real application windows and display configurations.
