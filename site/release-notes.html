Windows beta 0.1

Release notes

This is an early Windows build intended for focused testing. It demonstrates the complete Skribly interaction—contextual note, compact dot, focused editor and saved-note recovery—while some native edge cases remain under validation.

Included in beta 0.1

  • Attach a Skrib to an open Windows application.
  • Create text notes using a focused editor.
  • Switch to Write mode for mouse, touch or stylus drawing.
  • Add local images and small file attachments.
  • Close a completed note into a compact movable dot.
  • Open small notes as previews and larger notes in the composer.
  • Use Saved Skribs to review notes and reconnect to matching open applications.
  • Use Ctrl + Shift + Space as the global shortcut.
  • Keep text notes across application restarts.
  • Use the tray menu to show Skribly, create a note, open saved notes or quit.

Known limitations

  • The installer is currently unsigned, so Windows SmartScreen may display a warning.
  • Mixed-DPI multi-monitor behaviour is experimental.
  • macOS is not available.
  • Exact browser URL or DOM-element anchoring is not included.
  • Attachments are stored locally in the WebView profile and are not yet part of a portable export.
  • Licence activation and paid checkout are not active in this beta.

Commercial launch plan

The planned personal licence uses a seven-day full trial followed by a ₹999 one-time launch price. The purchased version remains usable permanently and includes twelve months of updates. Any update pass after that period will be optional.

Installation

Download the Windows x64 installer from the Skribly website. The same-site download route resolves the current validated installer without sending customers through the source repository.
