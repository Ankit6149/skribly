Repository-grounded audit · current product model

Skribli has outgrown its first UI hierarchy.

Capability has expanded faster than disclosure. Rich text, ink, attachments, repeating reminders, task/archive semantics, free resizing, contextual return, Rail scopes, library management, entitlement and recovery are all useful — but too many now compete at the same visual level.

CORE REDESIGN QUESTION
What is the smallest visible interface that makes the user's current intention obvious?

Everything else should stay one intentional gesture away. Skribli should feel embedded in the user's work, not like a second workplace.

Capability · strong

The product already does more than the UI needs to advertise.

Hierarchy · weak

Too many valid controls have become peers.

Presence · risky

Rail value is real, but clutter fatigue must be designed out.

Future readiness · fixable

A semantic gateway can absorb new annotation types.

Physical objects, precise shell

09 · motion & input

Motion explains state change; it does not decorate inactivity.

Every pointer animation also needs a keyboard/touch/stylus-equivalent path where relevant.

100–160 ms

Acknowledgement: hover/focus, small icon/state response.

180–280 ms

Object movement: attachment fan, rail reveal, small panel change.

300–450 ms

Meaningful transformation: note expands, return journey, re-anchor.

Reduced motion

Replace spatial travel with immediate state change and clear focus movement.

10 · future information architecture

Daily · Find · Control.

The future app structure should reduce management gravity instead of adding another navigation level.

Daily

Mostly outside the app window.

  • Shortcut → fresh Skrib
  • My Skribs edge presence
  • Reminder notifications
  • Return/re-anchor journeys
Find

The app's primary retrieval job.

  • Search/read any Skrib
  • Context and media filters on demand
  • Reminder/time lens
  • Past/Trash as lifecycle filters
Control

Low-frequency configuration.

  • Settings / appearance
  • Context & privacy
  • Data & recovery
  • Account / updates
