Living Paper v2 · post-review corrections

The note is the canvas. The Rail is a ribbon. Everything else gets out of the way.

This revision removes the permanent bottom `+ / Saved locally / Done` composition, removes Drawing as a separate surface, makes images/text/ink coexist on one Skrib, restores the stronger three-colour collapsed widget, simplifies the open Rail, and gives reminders a properly spacious calendar.

one mixed canvasink anywhereinline or free mediacontextual insertionthree-colour ribbonno Rail cardroomy calendar
Nothing that looks like a toolbar at rest

Capability appears where the user is working, not in a permanent command strip.

Ink belongs to the whole thought

Circle text, draw over screenshots, annotate between objects, keep typing afterward.

Presence adapts to windowed work

The Context Ribbon may follow the active app edge or stay fixed on a screen edge.

System UI remains professional

Settings, search, recovery and keyboard behavior stay conventional and exact.

03 · content placement

Inline if you want structure. Free if you want a canvas.

The app should not force one attachment philosophy on everybody. Smart placement is the default; Settings can make Inline, Free or Ask the preference.

Smart default recommended

Paste at caret → Inline. Drop into open paper space → Free. Drop on an insertion tick → Inline.

Selection override per object

When an image is selected, one small control changes Inline ↔ Free without reopening Settings.

Ink grouping explicit only

Moving an image does not drag surrounding ink unless the user intentionally groups selected strokes with it.

No mode wall important

Text, images, documents, video and ink remain one note. Richness should not feel like entering another app.

Animations should explain where the thought went

No ambient motion. Nothing should wiggle simply to look “creative.”

CURRENT DESIGN DIRECTION

Living Paper v2 is now about a mixed canvas + contextual ribbon, not a paper-styled toolbar.

The next review should concentrate on the exact Resting Skrib composition, how Ink feels with mouse versus pen, whether the Context Ribbon should follow the active app by default, and the open paper-fan geometry. Everything else can build consistently from those decisions.
