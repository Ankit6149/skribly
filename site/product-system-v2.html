SYSTEM CONTRACT

Clean visual rules + explicit recovery rules.

The same system governs desktop, note, widgets and phone. Delight comes from continuity and tactile content—not from decoration everywhere.

QUIET INK

System surfaces

Manrope/DM Sans, warm neutral backgrounds, thin borders, precise alignment, native window behavior, no handwritten labels for functional UI.

LIVING PAPER

Thought objects

Pastels, asymmetric paper corners and Kalam only when representing the user’s actual note, attachment or reminder object.

CONTEXT THREAD

Continuity & repair

Use subtle motion and place labels to show where a thought came from, where it is going and how to recover when the saved place is unavailable.

NO DEAD ENDS

Every failure has a next action

Retry when retry is meaningful; Open here when return fails; export/read-only when storage fails; account details when entitlement fails; never generic “Something went wrong.”

ONE INTENTION

One dominant action per region

Resting note writes. Expanded pill retrieves. Find searches. Reminders resurface. Settings controls. Do not mix all jobs together.

ACCESSIBLE BY DEFAULT

Not hover-dependent

Every hover action also appears on focus/touch. High contrast does not depend on pastels. Keyboard and reduced motion remain first-class.

Acknowledge100–160 msHover, press, focus, selection, saved check. No spring.
Reveal170–240 msTool tray, formatting bubble, widget fan, contextual fan. Origin anchored to the triggering object.
Recompose220–340 msNote grows for exact reminder / heavy work. Preserve context and restore user size afterward.
