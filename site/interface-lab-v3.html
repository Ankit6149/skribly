SIZE CONTROLS

Fast presets + custom freedom

Remember per SkribEach note returns to its last user size.
Temporary tool expansionDrawing/Reminder can grow to a safe workspace, then restore the prior size.
Monitor-safe boundsNever resize beyond the active work area.
Accessible alternativePresets provide keyboard control; dragging is not the only route.
Recommended production behavior

Keep manual resizing, but make it controlled: one hover/focus paper-corner affordance, minimum 380×300, maximum bounded by monitor work area, snap near Compact/Medium/Large, remember size per Skrib, and restore the user’s previous size after temporary Drawing/Reminder expansion. Avoid four visible resize handles.
