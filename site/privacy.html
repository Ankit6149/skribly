Privacy policy

Skribli is designed as a local-first Windows application. This policy describes the current pre-release application and public website without claiming deferred cloud, collaboration, or commercial services.

1. Application data

Skribli stores note text, note identifiers, timestamps, editor geometry, and contextual matching fields on your computer. Core note use is designed not to require a Skribli account or cloud service.

2. Limited context information

When you press the shortcut, Skribli reads limited local Windows information needed to validate the foreground target and place the compact editor. This may include process name, window title, window class, position, size, process identifier, and a temporary native window handle. The current shortcut path does not record your screen.

3. Local storage and recovery

Current note data is written to versioned local storage with recovery generations and metadata-only diagnostics. Diagnostics are designed not to contain note text or target window titles. Recovery, export/import, trash retention, and data-lifecycle behavior must be finalized and documented before public release.

4. Website data

The public website is hosted by Vercel. The hosting provider may process standard request information such as IP address, browser details, requested path, timestamps, and security logs to deliver and protect the site. Skribli currently adds no behavioural advertising, tracking pixel, or analytics cookie.

5. Downloads

Public downloads are disabled. The website does not resolve or deliver an installer while the exact Windows release candidate remains under lifecycle, installer, accessibility, recovery, and physical desktop validation.

6. Retention and deletion

The current compact editor can permanently delete a note only after explicit confirmation. Reversible trash, retention, restore, complete export/import, and attachment cleanup remain open release gates and are not advertised as available today.

7. Security and pre-release limitations

Skribli uses local storage and Windows-native integration, but unfinished software cannot guarantee absolute security. Do not store passwords, private keys, or highly sensitive regulated information in a development or release-candidate build.

8. Children

Skribli is a general productivity utility and is not directed to children under 13. The current website does not knowingly collect account information from children.

9. Changes

This policy may change as tested capabilities and data flows change. Material updates will use a new effective date and will be reflected in the development notes before public access is enabled.
