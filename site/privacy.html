Privacy policy

Skribli is designed as a local-first Windows contextual annotation application. This policy describes the current account-connected pre-release build and public website without claiming deferred sync, collaboration, or payment services.

1. Application data

Skribli stores Skrib text, identifiers, timestamps, lifecycle state, editor geometry, and contextual matching fields on your computer. This Skrib content is not uploaded to the account service.

2. Account and access metadata

A verified account is required for trial and write access. The temporary managed account service stores verified email, account identifier, trial and entitlement dates, a one-way Windows device claim, last-seen app version, and optional product-update consent. Changing account or reinstalling on the same device does not restart the device trial. Passwords and sessions are handled by the authentication provider; the desktop protects its session with Windows user-scoped encryption.

3. Limited context information

When you press the shortcut, Skribli reads limited local Windows information needed to validate the foreground target and place the compact editor. This may include process name, window title, window class, position, size, process identifier, and a temporary native window handle. The current shortcut path does not record your screen.

4. Local storage and recovery

Current note data is written to versioned local storage with recovery generations and metadata-only diagnostics. Diagnostics are designed not to contain note text or target window titles. The current All Skribs window can read, search, export, and perform portable JSON import for active and trashed note records. Portable JSON explicitly excludes IndexedDB drawings, attachments, and reminders. Import requires a local preview before apply, does not upload the selected file, and writes and verifies a note-record rollback backup before changing local notes.

5. Website data

The public website is hosted by Vercel. The hosting provider may process standard request information such as IP address, browser details, requested path, timestamps, and security logs to deliver and protect the site. Skribli currently adds no behavioural advertising, tracking pixel, or analytics cookie.

6. Downloads

Public downloads are disabled. The website does not resolve or deliver an installer while the exact Windows release candidate remains under lifecycle, installer, accessibility, recovery, and physical desktop validation.

7. Retention and deletion

Ordinary Delete moves a saved note into local Trash instead of removing it immediately. Skribli presents a 30-day recovery period, supports restoring the same note record, and requires a separate note-specific confirmation before permanent deletion. This release does not silently purge expired Trash; expired or invalid lifecycle records remain visible for review. Trash, restore, note-record export, and portable JSON import with mandatory preview and rollback are implemented. Automatic retention cleanup and user-configurable retention remain open.

8. Security and pre-release limitations

Skribli uses local storage and Windows-native integration, but unfinished software cannot guarantee absolute security. Do not store passwords, private keys, or highly sensitive regulated information in a development or release-candidate build.

9. Children

Skribli is a general productivity utility and is not directed to children under 13. Do not create an account if local law requires parental consent that has not been provided.

10. Changes

This policy may change as tested capabilities and data flows change. Material updates will use a new effective date and will be reflected in the development notes before public access is enabled.
