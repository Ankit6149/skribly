Privacy policy

Skribli is designed as a local-first Windows application. This policy describes what the application stores and what the public website processes during active production development.

1. Application data

Skribli stores note text, note metadata, positions, and context information on your computer. Normal note use is designed not to require a Skribli account or cloud service.

2. Context information

To attach notes to applications, Skribli reads limited information about open windows, such as the process name, window title, window class, position, size, and temporary native window handle. This information is used locally to match and position notes.

3. Website data

The public website is hosted by Vercel. As part of delivering the site, the hosting provider may process standard request information such as IP address, browser details, requested path, timestamps, and security logs. Skribli currently does not add behavioural advertising, tracking pixels, or analytics cookies.

4. Downloads

Public downloads are currently disabled. The website does not resolve or deliver an installer while the Windows application is being rebuilt and validated.

5. Retention and deletion

Deleting a note removes its saved note record. A dedicated export and deletion flow will be documented before a stable public release.

6. Security and production limitations

Skribli uses local storage and Windows-native integration, but unfinished software cannot guarantee absolute security. Do not store passwords, private keys, or highly sensitive regulated information in development builds.

7. Children

Skribli is a general productivity utility and is not directed to children under 13. The current website does not knowingly collect account information from children.

8. Changes

This policy may change as the product, optional diagnostics, or cloud features evolve. Material changes will be reflected by an updated effective date and production notes.
