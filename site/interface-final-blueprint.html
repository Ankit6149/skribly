Upper-right dog-ear Put Away

Click or Ctrl+Enter settles edits, saves, then hides. Save failure blocks the hide and leaves recovery visible.

Lower-right corner Resize

Native resize zone + one visual cue. This fixes the previous Done/resize conflict.

Contextual insertion not toolbar

Paste, drag/drop, `/`, or the subtle insertion dot. Smart placement decides Inline vs Free.

Ink anywhere same canvas

Stylus draws directly. Mouse uses temporary Ink state (`Alt+I` by default). Ink can cross text and images.

Reminder ≠ Task semantic

A reminder only resurfaces the thought. Completion exists only after explicit checklist/actionable intent.

Save feedback quiet

Success is a brief check. Errors become persistent because they require action.

07 · Codex Build Contract

What should actually be built, in order

Do not rewrite working domain logic just because the presentation changes. Replace the interface around proven persistence/context code incrementally.

1 · Freeze semantics

Put Away vs Complete. Reminder vs Task. Open Here vs Return. Context truth boundaries.

2 · Desktop presence

ContextRibbonHost, SmartAnchorPositioner, ContextFan, many/zero/hidden states.

3 · Skrib shell

Dog-ear Put Away, resize corner, context tab, mixed-canvas layers, no permanent toolbar.

4 · App + system

Library, Reminders, Settings, Account, tray, notifications, Quick Hide and recovery.

Preserve working logic important

Reuse current save/reminder/attachment/context behavior where correct. Split `SkribComposer.tsx` rather than blindly replacing the domain model.

Replace current Rail presentation specific

Reuse valid data/event plumbing from `ContextRail.tsx`; replace its card/navigation presentation with Ribbon + contextual fan.

Main app IA specific

Library becomes the default app landing. Past/Trash become Library filters. Settings absorbs low-frequency controls.

Acceptance gate required

QA zero/one/many Ribbon, windowed/fullscreen/multi-monitor, rich Skribs, save failures, read-only, DPI 100/125/150%, keyboard, reduced motion and unsupported target before calling the migration complete.

FINAL HANDOFF CANDIDATE

This is now specific enough to become the Codex implementation source.

The remaining review is product approval, not architecture discovery: confirm the Ribbon geometry, upper-right Put Away dog-ear, lower-right resize cue, Smart attachment placement, and Library-first app navigation. Once those are approved, Codex should implement against the Markdown contract and this interaction blueprint rather than improvising UI.
