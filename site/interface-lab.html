Rules demonstrated here

  1. One tool, one reserved row. Attach, Draw, Remind, Text, and Color never float above content.
  2. One-click sizing. The icon cycles Comfortable → Canvas → Compact and changes with the next action.
  3. Direct manipulation. Four visible-on-hover corner handles resize within safe minimum and maximum bounds.
  4. Less persistent copy. Save state and current size remain; keyboard hints and character count move out of the footer.

Persistence and location

  1. The rail stays mounted. Clicking rows updates the inspector; it never closes or jumps.
  2. Location is the second line. App → workspace/tab → exact depth is readable before opening.

Reminder added to the note

Reminder decisions

  1. A real calendar surface. Month, date, time, and repeat share one readable flow.
  2. No floating calendar over the note. Custom scheduling gets a focused sheet; quick choices stay in the inline tray.
  3. Repeat is visible. Common patterns are segmented buttons, not a hidden dropdown.
  4. The summary updates before save. Users can confirm the exact schedule in plain language.

Primary interaction map

Every click has one predictable result.

Ctrl + Shift + Space

Creates a fresh pastel note for the focused context.

Attach

Opens one inline tray; choosing a type adds a compact file chip.

Draw

Adds the ink toolbar as a reserved row and activates the shared canvas.

Color

Adds the pastel palette as a reserved row; swatches never cover the canvas.

Text

Reveals icon-first size and alignment controls in the same reserved row.

Remind

Shows quick choices inline; Custom opens the full date, time, and repeat surface.

Size

Cycles Comfortable → Canvas → Compact; icon always shows the next action.

Corner handle

Directly resizes the note within safe desktop bounds.

Header grip

Moves the note while keeping every edge contained by the active screen.

Done

Saves, then collapses the note to a small movable context dot.

Close

Removes the note surface; reopening its context restores it from local storage.

Note pill

Expands the persistent rail at the same screen-edge anchor.

Here / All

Filters the mounted rail without changing its position or selected note.

Rail note

Selects and previews. The rail stays open.

Open original

Restores the live app/window/location and opens the exact note.
