Pre-release validation

Public downloads are disabled.

Skribli has an active Windows codebase, but the exact release candidate is not yet approved for public installation.

Why is the download disabled?

The remaining gates include the complete note lifecycle, non-floating recovery library, reversible trash and export, installer upgrade and uninstall behavior, accessibility, and physical Windows validation. The website will not deliver an installer until those gates match one exact signed candidate.

What works in the repository now?

The current implementation includes a compact shortcut-opened editor, deterministic create-versus-reopen behavior, local storage and recovery foundations, truthful save states, safe Windows target capture, monitor-aware placement, tray onboarding, and extensive automated checks. These foundations do not by themselves make a public release complete.
