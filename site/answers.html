Skribli answers

Contextual notes, clearly explained.

Direct answers about the intended product and its current production status.

What is Skribli?

Skribli is a local-first contextual notes app for Windows. The intended flow is simple: focus the application where a thought belongs, press Ctrl + Shift + Space, write immediately, and close the note into a small attached tab.

What problem does it solve?

Ordinary notes remember text but often lose the surrounding situation. Skribli is designed to preserve application context so a reminder stays with the software where it is useful.

Why is there no app picker or permanent toolbar?

The production rebuild removes unnecessary floating controls. The shortcut should use the foreground application automatically, and empty overlay space must remain click-through.

Is Skribli private?

The core Windows experience is local-first and does not require an account, cloud sync, or screen recording. Skribli reads limited local window information only to identify and position the attached note. See the full privacy policy.

Can I download it now?

No. Public downloads are paused while the native overlay, shortcut flow, click-through behaviour, close controls, typography, and installer are rebuilt and validated.

Which systems are planned?

The current production work targets Windows 10 and Windows 11 on x64 computers. macOS is not available.
