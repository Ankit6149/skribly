Skribli answers

The current product, clearly explained.

These answers describe what the active Windows build does now, not deferred ideas or retired prototypes.

What is Skribli?

Skribli is a local-first contextual annotation app for Windows. The current build supports pastel typed and handwritten Skribs, pen/highlighter/eraser tools, local image/video/document attachments, one-time reminders, and a local calendar. Multiple simultaneous note windows, screenshot pins, checklists, and cloud sync are not claimed as shipped.

Does the shortcut create a new note or reopen one?

Native code makes that decision explicitly. With no match, Skribli creates one empty note. With an existing match, it reopens that note. Legacy duplicate data is resolved deterministically rather than by collection order. The editor labels the result as new or reopened.

What remains on screen after Done?

Done safely saves the active Skrib and folds it into one movable pastel dot. Select the dot to reopen the note. The background process and shortcut remain available in the Windows tray; the current v0 shows one active note or dot at a time.

What happens when saving fails?

Skribli keeps the editor visible and reports that the latest text is not safely stored. It does not hide the only visible draft or display a false saved state.

Is Skribli private?

A verified account is required for trial and write access. The service stores account and entitlement metadata plus optional update consent; it does not receive Skrib content. Skribli reads limited Windows identity and geometry information locally so it can validate the foreground target and place the compact editor safely. See the privacy policy.

Can I download it now?

Public downloads are disabled. The owner v0 Windows installer is available only through the key-protected owner download page.

Which systems are supported?

The current release target is Windows 10 and Windows 11 on x64 computers. macOS is not currently available.
