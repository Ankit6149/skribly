A-only visual atlas

Desktop widget ≠ app navigation.

The desktop side widget is the small three-colour object that follows or docks beside the app you are actually using. The Skribli app window is a completely separate control surface. This atlas shows both systems independently, then covers the note and lifecycle states around them.

desktop side widgetopened widgetwindowed appsfullscreen appsmixed canvasapp screensfailure states
Desktop presence stays tiny

The side widget earns only enough space to tell you whether thoughts exist here.

Opening reveals thoughts, not navigation

No Ready/Find/Settings inside the side widget. It only retrieves contextual Skribs.

App navigation stays inside the app

Ready, Find, Reminders and Settings belong to the Skribli window only.

Every state must be visible before implementation

Empty, many, hidden, windowed, fullscreen, error and recovery are first-class review states.

02 · placement

Windowed, fullscreen and multi-monitor

The widget should not assume every app fills a monitor. These are distinct placement states, not one generic edge mockup.

Fullscreen workspace

Fullscreen placement is deterministic and stationary.

Focused monitor
