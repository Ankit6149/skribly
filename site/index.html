Questions

What people need to know.

What is Skribly?

Skribly is a contextual notes app for Windows. It attaches notes to application windows, lets them collapse into compact dots, and helps you return to the relevant working context.

How is it different from Microsoft Sticky Notes?

Microsoft Sticky Notes is strong for general note capture and sync. Skribly focuses on in-place application context: notes follow the app, occupy a specific spatial position, and collapse into small movable anchors.

Can I try Skribly before paying?

Yes. The commercial model is a seven-day full trial with no card. During the current beta, the build is free while licence activation is being validated.

Is Skribly a subscription?

No. The planned personal licence is a one-time purchase. It includes permanent use of that version and twelve months of updates. An update pass after that period is optional.

Where are my notes stored?

The current Windows beta stores notes and attachments locally on the computer. See the privacy policy for the precise website and application data practices.

Does it support macOS?

Not yet. The current product is a Windows beta for Windows 10 and Windows 11.
