# Bundled app marks

These SVGs were downloaded from the [Supericons](https://supericons.dev/) icon service on 2026-09-27. The full `@supericons/mcp` pack is used only for lookup during development and is not redistributed in the app.

| File | Supericons reference | Upstream |
| --- | --- | --- |
| `googlechrome.svg` | `simpleicons:googlechrome` | [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 project; brand rights may differ |
| `firefox.svg` | `simpleicons:firefox` | [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 project; brand rights may differ |

The note uses these flat marks for known apps and extracts the actual Windows app icon when no bundled mark is available. The marks use Skribli's ink colour and the pill uses a fixed complementary pastel for each note colour. `../vscode-flat.svg` uses the silhouette from the [Microsoft Visual Studio Code stable icon](https://code.visualstudio.com/brand). Supericons currently offers an outline mark for this app, which was not suitable for this small pill.
